# Apply+

Apply+ is a CV writing website for job seekers in India, the UAE and all GCC countries. It offers ATS-friendly CVs and cover letters.

## Features

- ATS-friendly CV and CV + Cover Letter packages
- Client reviews with 5-star ratings
- Review form that opens WhatsApp
- Contact form that opens WhatsApp
- Smooth scroll animations
